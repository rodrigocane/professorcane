# 🏦 Exercício: Simulador de Caixa Eletrônico com Funções (Python)

Este exercício tem como objetivo praticar o uso de **funções em Python** por meio de um simulador simples de caixa eletrônico. A atividade foca na organização de código, uso de variáveis globais e construção de menus interativos.

---

## ✅ Funcionalidades obrigatórias:

Sua aplicação deve permitir que o usuário realize as seguintes ações:

1. 💰 **Ver saldo**  
   Exibe o saldo atual da conta.

2. 📈 **Depositar valor**  
   Permite o usuário informar um valor (positivo) a ser adicionado ao saldo. Também registra o depósito no extrato.

3. 📉 **Sacar valor**  
   Permite o usuário sacar um valor (se houver saldo suficiente). O saque é registrado no extrato.

4. 💸 **Ver extrato**  
   Mostra todas as movimentações realizadas (depósitos, saques, tentativas inválidas), seguidas do saldo atual.

5. 👋 **Encerrar conta**   
   Quando o usuário escolhe essa opção:
   - Se houver saldo positivo, o sistema **saca todo o valor restante**.
   - Em seguida, exibe uma mensagem de encerramento e encerra o programa.

---

## 📌 Regras e instruções:

- A conta começa com saldo igual a `0`.
- Toda movimentação deve ser registrada em uma **lista de extrato** (ex: `["Depósito: R$ 100.00", "Saque: R$ 50.00"]`).
- O programa deve rodar dentro de um **loop de menu**, até o usuário escolher encerrar a conta.
- Cada ação deve ser implementada como uma **função separada**, com nomes claros e objetivos.
- Quando for necessário alterar o valor da variável `saldo` dentro de uma função, utilize a palavra-chave `global`.

---
